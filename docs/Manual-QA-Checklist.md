# Чеклист ручной приёмки на устройствах

Этап 5 роадмапа ([Development-Roadmap.md](./Development-Roadmap.md)). Чеклист проходит владелец на своих
телефонах и компьютере. Он описывает только то, что уже есть в `main` на 13.10.2026; новых требований
здесь нет.

Как отмечать: в колонке «Итог» ставьте **ок**, **не ок** или **—** (не удалось проверить), в «Комментарий» —
что увидели. Каждое «не ок» — отдельное issue (раздел 9).

## 0. Перед началом

- **Два режима.** LIVE — настоящий сервер: баланс и результаты подтверждает сервер. DEMO — показ механики без
  сервера: результат придумывает сам браузер, баланс ненастоящий.
- **Где что проверять.** Разделы 1–3 и LIVE-часть разделов 4–7 возможны только после деплоя сервера по
  [Deploy-Production.md](./Deploy-Production.md) и подключения бота. До этого проверяется только DEMO:
  публичное демо <https://hainox.github.io/BURMALDOZA/> или Mini App без сервера.
- **Устройства.** iPhone (Telegram для iOS), Android (Telegram для Android), компьютер (Telegram Desktop).
  Отдельной колонкой отмечайте, на каком устройстве проверяли.
- **Как понять режим.** Вверху главного экрана есть плашка: **«LIVE API · SERVER-FIRST»** — LIVE,
  **«ДЕМО-КОНТУР»** — DEMO. У баланса подпись «Баланс · LIVE» или «Баланс · DEMO».

## 7. Сеть и повторные нажатия (LIVE)

| # | Шаг | Ожидаемый результат | Итог | Комментарий |
|---|---|---|---|---|
| 7.1 | Быстро нажать спин два-три раза подряд | Проходит один спин, деньги списаны один раз (сверить с `/balance`) | | |
| 7.2 | Включить авиарежим во время спина, через 5–10 секунд выключить | Подпись у баланса меняется на OFFLINE, затем обратно на LIVE; результат и баланс правильные, ставка не списана дважды | | |
| 7.3 | Открыть одну комнату на двух устройствах и сделать ход на одном | Второе устройство не может повторить старый ход; после обновления видит актуальное состояние | | |
| 7.4 | Медленный интернет (например, далеко от Wi-Fi) | Итог приходит без дублей, баланс совпадает с `/balance`; записать, как долго ждали и что было на экране | | |

## 9. Как сообщить о проблеме

Создайте issue в <https://github.com/Hainox/BURMALDOZA/issues> с меткой `to:codex`. Не пишите в issue
Telegram ID, номер телефона, токены и адрес сервера: репозиторий публичный.

```text
Пункт чеклиста: 4.2
Устройство и версия Telegram: Android 15, Telegram 11.x
Режим: LIVE / DEMO
Шаги: что нажимали по порядку
Ожидалось: …
Произошло: …
Скриншот или запись экрана: приложить
```
