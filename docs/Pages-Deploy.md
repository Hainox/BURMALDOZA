# Бурмалдоза — deploy demo на GitHub Pages

## Что уже подготовлено

- Статический demo-build: `docs/pages-demo/index.html`.
- GitHub Actions workflow: `.github/workflows/deploy-pages.yml`.
- В демо нет Telegram-токена, базы, платежей, авторизации, реальных денег или сохранения результатов.

## Публикация

1. Использовать публичный репозиторий `Hainox/BURMALDOZA` (уже создан владельцем).
2. Загрузить текущий foundation в ветку `main`.
3. Открыть **Settings → Pages → Build and deployment → Source** и выбрать **GitHub Actions**.
4. Запушить `main` либо запустить workflow **Deploy Pages demo** вручную.
5. После успешного развёртывания GitHub покажет `https://hainox.github.io/BURMALDOZA/` в summary workflow. Регистр пути соответствует названию репозитория.

Workflow публикует отдельную HTML-страницу, а не SvelteKit-приложение. На GitHub Pages нельзя запустить Python API или Telegram polling-бота.

## Ручная проверка перед показом

1. Открыть URL с телефона и с desktop.
2. Убедиться, что кнопка «Крутить» принимает ставку 10–500 Ⓜ и меняет только локальное состояние страницы.
3. Сделать три ставки: первые две дают демонстрационный выигрыш, третья — проигрыш. Исход задан сценарием, а не случайностью; это не модель вероятностей реальной игры.
4. Обновить страницу: баланс должен вернуться к 4 260 Ⓜ, история — к стартовым примерам.
5. Проверить, что на странице нет полей для платежей, username, Telegram-авторизации или реальных сумм.
