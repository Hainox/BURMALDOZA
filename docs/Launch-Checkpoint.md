## Принятые решения

- **YUVI выводится из эксплуатации.** Сервер `82.23.173.215` переходит под Бурмалдозу,
  репозиторий `YUVI-BOT-v2` архивируется, токен YUVI-бота отзывается. Данные YUVI не переносятся:
  старый SSH-ключ к серверу утерян.
- **Домен:** `https://burmaldoza.ru` — основной адрес, `burmaldoza.online` перенаправляется на него.
- **Схема:** Mini App и API на одном домене за Caddy (TLS от Let's Encrypt). Наружу открыты только
  порты 80/443 (плюс 22 и 9443 для Portainer). PostgreSQL, Redis и API без публичных портов.
- **Кто делает деплой:** локальный агент на ПК владельца (Codex или Claude Desktop с Desktop
  Commander). Облачный Claude до сервера по SSH не достаёт, поэтому проверяет PR деплоя.
- **Ключ:** секретная половина остаётся только на ПК владельца; в репозиторий, `.env` и чаты она
  не попадает. Для автодеплоя позже — отдельный deploy-ключ в GitHub Secrets.
- **Сертификаты:** Let's Encrypt через Caddy. Бесплатный DomainSSL от Рег.ру и хостинг
  Reg.Host-0 для Бурмалдозы не нужны.

   «Переустановить».

   администратора.
