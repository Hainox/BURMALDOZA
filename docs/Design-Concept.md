# Бурмалдоза — Design concept

## Направление

Native mobile-first lounge: тёмный ink-фон, винные поверхности, латунное подтверждение и один доминирующий игровой stage. Визуальный язык — приватный клуб после полуночи, а не кричащий «автомат».

Сейчас комнаты используют authored CSS primitives и нейтральные символы. Финальные женские персонажи, мемные сцены, логотип и тематический арт подключаются только после приёмки foundation.

## Первый путь

1. `/casino` открывает Mini App.
2. API проверяет raw Telegram `initData` и возвращает профиль/баланс.
3. Пользователь выбирает Slot, Blackjack или Hold’em.
4. Клиент отправляет action intent с idempotency key и ожидаемым `state_version`.
5. Сервер рассчитывает исход, пишет ledger и публикует подтверждённое событие.
6. Mini App проигрывает только ту хореографию, которую разрешает подтверждённое состояние.

## Motion system

Единая последовательность: `idle → primed → resolving → outcome → settle`.

- Slot: независимые stop-ритмы барабанов, payline появляется только в `outcome`, выигрышный символ не «угадывается» заранее.
- Blackjack: staggered deal, hole-card сохраняется закрытой до разрешённой фазы, действия блокируются на `resolving`.
- Hold’em: раскрытие community cards по порядку, pot и turn остаются читаемыми, результат объясняет hand state.
- Reconnect/navigation сбрасывает motion в `idle` и сначала возвращает snapshot.
- `prefers-reduced-motion` убирает декоративные циклы и схлопывает промежуточные фазы, но сохраняет legal actions и объяснение результата.
- Ошибки, loading и offline — самостоятельные визуальные состояния; никакой бесконечной «загрузки ради красоты».

## Экранный состав v1

- Home: баланс, connection boundary, demo/production status, комнаты.
- Game: ставка/действие, ruleset, stage, legal controls, confirmed result band.
- Wallet: история операций и причины изменения баланса.
- Leaderboard: недельный/общий рейтинг после отдельного решения о публичности.
- Profile: Telegram display name, статистика, opt-in настройки.
- Admin: только для ролей — лимиты, модули, анонсы, аудит.

## Контент и безопасность

- Тон живой и ироничный, но без давления, обещаний дохода и «почти выиграл» манипуляций.
- Любая вероятность, лимит и изменение баланса объясняются рядом с действием.
- Публичность выигрыша только opt-in; бот не спамит чат.
- Jokergem — внутриигровая единица без денежной ценности; переименование не должно менять integer balances.
- Аватары и персонажи не являются источником правил игры и не должны закрывать результат/контролы.

## Нужные материалы до thematic pass

- утверждённые исходники нового логотипа и avatar crops;
- 3–6 визуальных референсов с правами использования;
- финальный copy/тон для трёх комнат;
- решение по звуку, haptic feedback и публичному share;
- таблицы выплат и лимитов для каждой themed ruleset version.
