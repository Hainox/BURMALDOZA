# Локальный журнал проекта

Откройте `docs/project-journal/index.html` в браузере двойным щелчком. Сервер, установка пакетов и GitHub Pages не нужны. HTML, CSS, JavaScript и встроенный снимок лежат в этой папке.

При открытии сразу показывается датированный снимок публичных Issues и PR. Кнопка «Обновить из GitHub» читает общедоступные GitHub API для всех страниц Issues и PR (до 1000 записей каждого типа) и текущего `main`, после чего сохраняет ответ в `localStorage`. Если сеть или лимит API мешает обновлению, страница явно показывает самый свежий ответ из памяти вкладки, кэша или встроенного снимка вместе с датой. Браузер может запретить `localStorage` на `file://`; это не мешает открыть страницу, но свежий ответ тогда не переживёт перезапуск.

Статусы этапов — редакционные сводки из [Development-Roadmap.md](../Development-Roadmap.md) и [BuildSpec.md](../../dev/BuildSpec.md), а не вычисление готовности по числу PR. Этапы 1–3 завершены только как foundation/skeleton; production и ручная приёмка не подтверждены. Тексты handoff основаны на связанных issue и [Command-Code-Workflow.md](../Command-Code-Workflow.md). Перед передачей задачи сверяйте live gate и allowlist в исходном issue.

Ручная проверка: найдите `#43`, выберите `Issues`, `Открыт`, `Command Code` — остаётся мобильное QA. Сбросьте фильтры и выберите `Pull requests`, `Слит` — видны завершённые работы, включая #40 и #47. На снимке 03.10.2026 открытых PR нет. Нажмите «Обновить» при доступном GitHub API, проверьте источник и время. Отключите сеть и повторите: должен остаться последний кэш/снимок с явным сообщением об ошибке. Пройдите элементы клавишей Tab, скопируйте промт в очереди и проверьте экран 320, 768 и 1440 CSS px, а также настройку reduced motion.

## Серверы для просмотра с обновлением файлов

Из корня репозитория после `pnpm install --frozen-lockfile` запустите в двух терминалах:

```bash
pnpm miniapp:dev --host 0.0.0.0 --port 5173 --strictPort
pnpm --dir apps/miniapp exec vite ../../docs/project-journal --host 0.0.0.0 --port 5174 --strictPort
```

Во второй команде путь отсчитывается от `apps/miniapp`.
Mini App — `http://localhost:5173/`, журнал — `http://localhost:5174/` на машине, где работают процессы. Vite подхватывает изменения файлов. Обновление GitHub — кнопкой в журнале; автоматического фонового опроса GitHub эта страница не выполняет. Игровое приложение вне Telegram без API остаётся DEMO.

В облачном окружении адреса относятся к облачному контейнеру. Они не означают, что сервер запущен на ПК владельца; доступ из браузера требует проброса порта средой.

Локальная автоматизированная проверка без браузера: `node docs/project-journal/test-offline.cjs`. Она воспроизводит успешное обновление при запрете `localStorage`, затем сетевую ошибку и проверяет сохранение самого свежего ответа в памяти вкладки.
