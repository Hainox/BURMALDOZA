# Рабочий процесс Codex ↔ Command Code

**Дата фиксации:** 21 сентября 2026 года
**Назначение:** передавать в CCode только изолированные задачи с измеримым результатом и заранее указанной моделью.

## Маршрутизация моделей

| Задача | Модель | Effort | Правило |
| --- | --- | --- | --- |
| Основная реализация UI и motion | `meta/muse-spark-1.3-contributor` | `high` | Основной выбор для самостоятельной работы в репозитории. |
| Архитектурная проверка и финальный review | `gpt-5.6-sol` | `high` | Использовать для критичных контрактов, сложных merge и финального аудита. |
| Небольшие независимые правки | `deepseek/deepseek-v4.1-flash` | `medium` | Быстрые локальные задачи; не делать единственным маршрутом проекта. |
| Резервный быстрый исполнитель | `z-ai/glm-5.3-flash` | `high` | Применять при недоступности основного исполнителя или для второго прохода. |
| Локальная бесплатная проверка | `qwen3-8b-local` | `low` / `/no_think` | Форматирование, чтение diff, простые проверки без сложного проектирования. |

Идентификатор модели и effort указываются в каждом handoff явно. DeepSeek не используется как единственная дорога: ранее для него уже встречался `429`, поэтому у задачи всегда должен быть запасной маршрут.

## Правила расхода Pro

- перед дорогой задачей проверить `/usage`;
- не включать автоматический top-up без отдельного решения владельца;
- сильную модель оставлять для архитектуры, motion-критичных задач и финального review;
- отправлять в сессию только нужный контекст, без несвязанных старых диалогов;
- задача должна иметь ограниченную область файлов и проверяемый acceptance checklist.

## Ближайший handoff для Slot v2

```text
Репозиторий: Hainox/BURMALDOZA
Ветка: ccode/slot-v2-motion
Модель: meta/muse-spark-1.3-contributor
Effort: high

Собери визуальный слой комнаты Slot v2. Работай только в разрешённых файлах:
- apps/miniapp/src/lib/rooms/SlotRoom.svelte;
- slot-only компоненты и стили рядом с ним.

Не меняй domain, RNG, ledger, API contracts и server fixtures. Не подменяй
серверный SlotOutcome локальным результатом.

Acceptance criteria:
- барабаны прокручиваются полной вертикальной лентой;
- есть разгон, инерционное торможение и последовательная остановка левый → центр → правый;
- итоговая сетка берётся из подтверждённого результата;
- выигрышная линия и выплата подсвечиваются после остановки;
- есть визуальное состояние Free Spins и счётчик вращений;
- reduced-motion сохраняет смысловую последовательность;
- Playwright проверяет запуск, остановку и стабильный финальный результат.
```
