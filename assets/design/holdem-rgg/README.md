# Hold'em · Камуро-тё — превью комнаты

Интерактивное превью: [`preview.html`](./preview.html) (пулы героев — [`roster.js`](./roster.js)).
Задача — #62. Решения владельца 13.10.2026: тема — игры RGG Studio (Yakuza / Like a Dragon, Judgment); соперники-боты —
герои серии; каждая раздача — новый соперник из пула, распределённого по стоимости столов.

## Визуал

По мотивам артов серии: лобби на рисовой бумаге (васи) с тушью, кистевыми иероглифами и красной печатью-ханко на
каждом столе; раздача — кинематографичная тьма с прожектором сверху и дымом у пола, тёмно-лаковое сукно с ирэдзуми-волнами
и золотой окантовкой; на заднем плане — ворота Камуро-тё со светящейся вывеской 神室町. Перед раздачей — заставка героя
как в серии (доработка 13.10.2026): ч/б стоп-кадр с размытыми краями, имя красным маркером (Permanent Marker) с белой
обводкой и подпись — титул героя (17 героев) или его игра. Рубашка карт — золотой дракон с жемчужиной. Команды — наклонные плашки, как боевое меню серии; итог — печать 勝 / 負 / 分.

## Пулы и выбор соперника

- 229 героев (из 230 в архиве владельца) распределены по столам: 1 000 «Легенды» 伝説 — 34 (главные герои, патриархи,
  главные злодеи), 500 «Капитаны» 幹部 — 85, 100 «Улица» 街 — 110. Распределение — предложение.
- Сервер выбирает героя «мешком»: без повторов, пока игрок не встретит весь пул стола. Герой — только оформление бота;
  стратегия задаётся столом. В живом режиме — аватар Telegram соперника.

## Ассеты и права

`intro/` — 229 кадров заставок 640×360 WebP (2,6 МБ); `roster/` — 229 аватаров 256×256 WebP, обрезанных по найденному лицу (OpenCV) из кадров профилей персонажей вики-галерей
серии (© SEGA / Ryu Ga Gotoku Studio); исходник, ссылка и SHA-256 — в [`sources.json`](./sources.json). Без найденного
лица — 4 героя (центр по умолчанию), два кадра поправлены вручную, Минору Дайдодзи исключён (кадр в больничной койке).
Логотипов серии нет; стол, колода, печати и интерфейс нарисованы с нуля. Решение владельца: некоммерческое фанатское
превью с атрибуцией, как GFL в Blackjack; общая лицензия не заявляется.
