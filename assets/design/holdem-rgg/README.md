# Hold'em · Камуро-тё — превью направления

Интерактивное превью: [`preview.html`](./preview.html). Открыть двойным щелчком или через локальный сервер.
Задача — #62; решение владельца 13.10.2026: тема Hold'em — игры RGG Studio (Yakuza / Like a Dragon, Judgment).

## Что показано

- Вкладка «Столы»: режим «Против бота» / «Живой игрок» (поиск до 60 с), три стола 100 / 500 / 1 000 JOKERGEM с
  блайндами из проекта BuildSpec (PR #61, ждёт утверждения).
- Вкладка «Раздача»: стол heads-up — лакированный красный борт с золотой окантовкой, зелёное сукно; портреты с
  кольцом таймера 20 с; банк; борд по улицам; наклонное меню действий «Колл / Рейз / Чек / Сбросить».
- Записанная раздача A♠ K♠ против Q♥ Q♣ до шоудауна: карты соперника открываются только на шоудауне, при сбросе —
  никогда; выигрышные пять карт подсвечены; итог — печать 勝 / 負.
- Три бота-соперника по столам: Кэнта «Чинпира», Рю «Вакагасира», Гэндзо «Оябун» — оригинальные персонажи.
- Рубашка колоды: сэйгайха, красный круг с золотым мотивом, знак 賭.
- Reduced motion: без полётов карт и удара печати.

Раздача в превью заранее записана для показа движения. В игре карты, ходы бота и итог определяет сервер.

## Права

Серии Yakuza / Like a Dragon и Judgment — игры SEGA / RGG Studio. В превью нет их логотипов, артов, героев,
моделей и скриншотов: только атмосфера квартала и собственные SVG-иллюстрации.
