# Blackjack GFL — Deck A design checkpoint

Выбранное владельцем направление: портретные карты-досье, рубашка A / S09, форпост G&K в секторе 09, ранний сюжет GFL 1 (2062).

## Оригинальные концепты

- [Комната Sector 09](./generated/sector-09-room-concept.png)
- [Рубашка A / S09](./generated/card-back-a-s09.png)

Это дизайн-концепты для дальнейшей приёмки; они не меняют правила Blackjack, RNG, серверный результат или баланс. Звуковая часть пока описана только как концепция: генератор/вентиляция, редкие радиопомехи, короткий звук слайда карты. Игровые SFX в репозитории отсутствуют.

## Персонажи и атрибуция

- Порядок 52 карт Deck A зафиксирован в [интерактивной матрице состава](../../../../docs/design/blackjack-card-roster.html).
- Портреты T-Doll и ссылки на страницы файлов собраны в [sources.json](./sources.json); изображения принадлежат MICA Team / SUNBORN.
- По уточнению владельца проекта, MICA публикует материалы GFL для фанатского распространения и привлечения новых игроков. Портреты включены в этот неофициальный дизайн-чекпойнт с атрибуцией; это не означает передачу прав или открытую лицензию на иные способы использования.
- [Интерактивное превью на GitHub Pages](https://hainox.github.io/BURMALDOZA/design/blackjack-deck-a/) показывает комнату, рубашку и все 52 карты; есть поиск, фильтры и карточки-досье. [Мобильный контактный лист](../../../../docs/design/blackjack-gfl-deck-a-preview/README.md) остаётся запасным быстрым просмотром.

Этот checkpoint фиксирует визуальное направление и источники. Игровые правила, RNG, серверный результат и баланс не меняются; SFX пока описаны только как концепция.
