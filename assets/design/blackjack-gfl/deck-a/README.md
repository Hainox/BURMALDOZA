# Blackjack GFL — Deck A/B design checkpoint

Для Mini App выбрана Deck A: портретные карты-досье и рубашка A / S09. Deck B доступна только для визуального сравнения в интерактивном превью. Мир — Girls' Frontline 1 после Collapse.

## Оригинальные концепты

- [Актуальная комната: заброшенное здание с полицейским периметром](./web/room-police-perimeter.png)
- [Рубашка A / S09](./generated/card-back-a-s09.png)

Комната изображает современное заброшенное здание, окружённое полицейским периметром. Это последнее решение владельца и оно заменяет ранний концепт базы без оцепления; стилизации под WWII или Rainbow Six Siege здесь нет. Концепты не меняют правила Blackjack, RNG, серверный результат или баланс.

Звук пока описан только как направление: дождь, генератор/вентиляция, редкие приглушённые переговоры по рации и далёкая сирена; для UI — слайд карты и подтверждённый сигнал результата. Звуковых файлов в репозитории нет, воспроизведение не имитируется.

## Персонажи и атрибуция

- Порядок 52 карт Deck A и 52 карт Deck B зафиксирован в [интерактивной матрице состава](../../../../docs/design/blackjack-card-roster.html).
- Портреты T-Doll и ссылки на страницы файлов собраны в [sources.json](./sources.json) и [sources-deck-b.json](./sources-deck-b.json). В Deck B найдено 51 изображение; источник PTRS не подтверждён и в превью стоит нейтральный placeholder.
- Владелец одобрил изображения для этого некоммерческого GFL fan-превью с атрибуцией MICA Team / SUNBORN. Это согласование не заявляет общую открытую лицензию на повторное использование.
- [Интерактивное превью на GitHub Pages](https://hainox.github.io/BURMALDOZA/design/blackjack-deck-a/) показывает комнату, рубашку и позволяет переключать Deck A/B; есть поиск, фильтры и карточки-досье. [Мобильный контактный лист](../../../../docs/design/blackjack-gfl-deck-a-preview/README.md) содержит снимки Deck A.

Этот checkpoint фиксирует визуальное направление и источники. Игровые правила, RNG, серверный результат и баланс не меняются; SFX пока описаны только как концепция.
