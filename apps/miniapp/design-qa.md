## Сравнение и исправления

В CUA/Chrome источник и живой iframe были показаны вместе в одном comparison input,
оба в размере 390×844 CSS px. Временная comparison-страница не входит в продукт.
Масштаб Chrome одинаков для обеих колонок; исходник нормализован до CSS размера.
Полная композиция и читаемые области header / порталы / CTA / bonus проверены рядом.

- P2, первый проход: дополнительная видимая строка выбранной активности и высокий
  hero сдвигали бонус под нижнюю навигацию. Убрана видимая строка (сохранено live
  объявление для screen reader), hero 290→280 px; CTA получил компактный отступ.
- P2, первый проход: заголовок меньше источника; мобильный размер поднят с 7.4vw до 8.4vw.
- P2, первый проход: невыбранные порталы слишком затемнялись; brightness .70→.88,
  saturation .80→.90. SOPPO читается даже до выбора Blackjack.
- Второй combined screenshot: бонус и CTA видны, заголовок/контр/порталы соответствуют
  общей композиции, три маскота не перекрывают controls. Эти находки закрыты.

## Пять поверхностей

- Typography: serif display Georgia/Times fallback, sans Inter/system controls;
  основной заголовок в одну строку на 390px, на 320px без горизонтального overflow.
  Точное семейство исходного raster mock неизвестно; Georgia — визуально близкая замена.
- Spacing: три равных portal tracks, gold CTA, reception сверху, bonus ниже;
  fixed nav с safe-area padding. Широкий экран ограничивает основной контент 600px.
- Color: ink surfaces, brass gold CTA/header, teal Blackjack, red Hold’em;
  основной текст светлый, выбранный portal ярче и чуть выше остальных.
- Images: реальные WebP, три соответствующих персонажа, читаемые арки/карты;
  SOPPO — утверждённое владельцем дополнение. Logo также raster, иконки библиотечные SVG.
- Content: title/subtitle/nav совпадают с выбранным направлением. SKELETON из mock
  удалён согласно BuildSpec; бонус обещает только реальные условия внутри. DEMO обозначен.

## Взаимодействия и ограничения

E2E: выбор отдельно от входа, вход/возврат и сохранение выбора/паузы, keyboard nav,
DEMO history/ranking/bonus без выдуманных данных, artwork загрузился на 320/390/1440px,
reduced motion; существующие mocked LIVE loading/error/empty/grant/ledger сценарии зелёные.
CUA проверяет живую локальную страницу, не production. Telegram iOS/Android и реальный
API требуют ручной проверки владельцем. Независимый code review — отдельный gate.

## Ручная проверка

1. Открыть хаб; проверить три встречающих маскота и SOPPO в Blackjack.
2. Выбрать каждый портал и нажать «Открыть комнату», затем «Назад к комнатам».
3. Переключить «Рейтинг», «История», вернуться в «Играть», раскрыть бонус.
4. Остановить фон кнопкой справа сверху; перейти в комнату/назад — пауза сохранена.
5. Включить reduced motion устройства: циклы остановлены, переключатель disabled.
6. Проверить 320px, portrait/landscape, Telegram safe areas, клавиатурные фокусы.
7. В LIVE проверить реальные loading/error/retry, подтверждённый баланс/выдачу и историю.

Незакрытых P0/P1/P2 визуальных находок локального прохода нет. P3: точная форма отдельных
арок/блики отличаются от исходной генерации; это новые согласованные растровые ассеты.
