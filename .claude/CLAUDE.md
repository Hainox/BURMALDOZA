## Claude Code в облачной сессии (claude.ai/code)

Дополняет корневой `CLAUDE.md` для запуска в облачном контейнере, а не в локальном CLI.

- Авторизация задаётся самой облачной сессией Claude-аккаунта владельца; проверка `/status` и
  `ANTHROPIC_API_KEY` из корневого `CLAUDE.md` относится к локальному CLI. Если в облачном окружении
  всё же задан `ANTHROPIC_API_KEY` — остановиться и спросить владельца, не печатая значение.
- Зависимости и Chromium для Playwright ставит `.claude/hooks/session-start.sh` (он же выставляет
  `PLAYWRIGHT_BROWSERS_PATH`). Docker недоступен — интеграционные тесты с PostgreSQL проверяются в CI.
- SSH к серверам нет: деплой выполняет владелец; агент готовит файлы и точные команды.
- Последний аудит кода: [docs/Code-Audit-2026-09-23.md](../docs/Code-Audit-2026-09-23.md).
